# LiveEdits Streamer Client Agent 🎮

אפליקציה ייעודית למחשב של הסטרימר. 

### תפקיד האפליקציה:
1. **חיבור ישיר ל-OBS Studio:** מתחברת מקומית אל ה-OBS WebSocket (פורט 4455).
2. **Stream Deck מקומי:** מספקת ממשק כפתורים פשוט ומהיר (ריאקשן, דרמה, גיימינג, חפיפה וכו') הנגיש מהמחשב או מכל טלפון/טאבלט ברשת הביתית (פורט 5050).
3. **הגדרת קאנבס 4K בלחיצה אחת:** מבטיחה ש-OBS מקליט ב-4K Grid מושלם (3840x2160) לחלוקה ל-4 שכבות.
4. **עצמאות מלאה וסנכרון:** עובדת ישירות מול OBS גם אם אין אינטרנט, ומסנכרנת את ההקלטות לשרת הראשי עבור העורכים.

### איך מפעילים:
```bash
python streamer_client/streamer_agent.py
```
והממשק ייפתח בכתובת:
`http://127.0.0.1:5050`
